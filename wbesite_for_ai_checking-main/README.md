# AI Photo & Video Authenticity Checker

## Overview
The **AI Photo & Video Authenticity Checker** is a web-based application designed to help users—specifically focusing on an accessible, senior-friendly experience—determine whether a piece of media was created by a human or generated by Artificial Intelligence. 

This project was built for a Software Engineering course and features a custom-trained Convolutional Neural Network (CNN) built with PyTorch, served through a Python Flask backend, with a clean, high-contrast vanilla HTML/CSS/JS frontend.

## Features
* **Senior-Friendly UI/UX:** Features large typography, warm and high-contrast colors, clear step-by-step instructions, and tactile UI elements designed for older adults.
* **AI Detection:** Uses a custom PyTorch `ImageCNN` model to classify images as "Human-Made" or "AI-Generated".
* **Confidence Scoring:** Displays the model's confidence percentage alongside the prediction.
* **Safety & Transparency:** Includes mandatory disclaimers about AI inaccuracies (false positives/negatives) to ensure users do not rely on it for critical decisions.
* **Single File Processing:** Frontend validation ensures only one file is uploaded at a time, complete with a visual loading bar to prevent user confusion during processing.

## Tech Stack
* **Frontend:** HTML5, CSS3 (Custom warm theme)
* **Backend:** Python, Flask
* **Machine Learning:** PyTorch, Torchvision, Pillow, Scikit-learn

## Installation & Setup

### Prerequisites
* Python 3.8 or higher
* Git (optional, for cloning)

### Step-by-Step Guide
1. **Navigate to the project folder:**
   Open your terminal and navigate to the project directory:
   ```bash
   cd path/to/ai-photo-checker
   ```

2. **Create a Virtual Environment (Recommended):**
   ```bash
   python -m venv venv
   ```
   * Activate on Windows: `.\venv\Scripts\activate`
   * Activate on Mac/Linux: `source venv/bin/activate`

3. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the Server:**
   ```bash
   python app.py
   ```

5. **Access the Website:**
   Open your web browser and go to: **`http://127.0.0.1:5000`**
   *(Note: Do not use VS Code Live Server (port 5500) to view the site, as it cannot run the Python backend).*

## Usage
1. Open the application in your browser.
2. Select whether you want to check a **Photo** or a **Video** from the main menu.
3. Click the upload area to select a single file from your device.
4. Click **Check This Picture/Video**. A loading bar will appear while the backend processes the media.
5. View the results, which include the classification, a confidence score, and a tool disclaimer.

## Model Details & Limitations
The current prototype uses a custom CNN (`ImageCNN`) trained on a small dataset (200 images). 
* **Disclaimer:** Because the dataset is small, the model's real-world accuracy is limited. It serves as a proof-of-concept for the software engineering pipeline (Client-Server architecture) rather than a production-ready forensic tool. 
* **Future Work:** To achieve higher accuracy, the model should be swapped with a pre-trained backbone (e.g., ResNet50) using transfer learning on a much larger dataset of AI/Real imagery.
